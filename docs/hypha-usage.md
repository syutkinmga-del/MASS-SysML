# Использование Hypha для семантической сверки

Hypha помогает находить положения OMG SysML v2 и KerML, анализировать их семантику и обосновывать предлагаемые изменения модели. Это источник для исследования и аргументации, а не средство проверки корректности модели.

## Установленная база и версии

- Рабочая база знаний проекта — релиз **2026-07**. Перед использованием проверьте фактический статус через MCP-инструмент `hypha_release_status`: нужный релиз и артефакты должны быть установлены и доступны.
- Версии компонентов Hypha независимы: версия пакета Hypha в checkout — **v3.0.0**, запускаемый MCP server — **2.0.0**. Не трактуйте эти номера как версии одного компонента.
- Совпадение обозначения **2026-07** с релизом SysML v2 Pilot не означает идентичность источников или артефактов. Указывайте отдельно, какой именно Pilot distribution или Hypha knowledge base использовался.

## Порядок сверки

1. Вызовите `hypha_release_status` и подтвердите релиз по умолчанию и состояние необходимых артефактов.
2. Найдите релевантные термины и положения средствами поиска Hypha. Для нормативного вывода найдите пункт спецификации и прочитайте его текст инструментом чтения пунктов; одного поискового фрагмента недостаточно для цитирования.
3. В обосновании укажите релиз, документ (SysML v2 или KerML), номер пункта и источник. Для ссылок используйте адреса и идентификаторы источника, фактически возвращённые Hypha; не подменяйте их предположительными ссылками.
4. Явно отделяйте:
   - **Нормативный текст** — текст пункта спецификации, полученный Hypha, с номером пункта и ссылкой на источник.
   - **Метамодель** — структурные определения, типы, кратности, наследование и ограничения модели языка, полученные из метамодели Hypha. Не выдавайте их за цитату спецификации.
   - **Интерпретацию** — вывод о применении найденных положений к MASSKernel или предлагаемому изменению. Обозначайте её как анализ, а не как прямое требование спецификации.
5. Если Hypha, нужный релиз или нормативные тексты недоступны, зафиксируйте ограничение и точную причину, если она сообщена инструментом. Не заявляйте, что нормативная сверка выполнена без полученного текста и источников.

## Границы проверки

Hypha не заменяет валидацию через закреплённый OpenSysML, проверку совместимости с SysML v2 Pilot, регрессию инвариантов SK1–SK16 или competency questions CQ1–CQ12. Результат поиска в базе знаний сам по себе не подтверждает синтаксическую или семантическую корректность модели, выполнение сценариев либо совместимость.
